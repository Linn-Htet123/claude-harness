# Claude auto-memory snapshot

Copies of `~/.claude/projects/-Users-tharlinhtet-my/memory/*.md` from Larry's main Mac.
`setup-new-mac.sh` installs them on a new Mac (only if missing) so a fresh Claude session
knows about the harness, Herdr, the loop, and the weekly task without this conversation.

Refresh from the main Mac:
```bash
cp ~/.claude/projects/-Users-tharlinhtet-my/memory/*.md ~/GITHUB/claude-harness/memory/claude-auto-memory/
```
